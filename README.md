# 分割ランチャー (SplitLauncher)

選んだ2つのアプリを画面分割で同時に起動する Android アプリです。

## 機能
- 左右それぞれのアプリを、インストール済みアプリ（アイコン付き）のプルダウンから選択
- 分割比率を 20%〜80%（5%刻み）で指定、プレビュー表示
- 起動方法を2種類から選択
  - **分割画面（標準）**: Android の分割画面で起動。比率はユーザー補助サービスがディバイダーをドラッグして調整
  - **フリーフォームウィンドウ**: ウィンドウ位置とサイズを直接指定するので比率どおりに開く（対応端末のみ）
- 組み合わせをホーム画面ショートカットとして保存（ワンタップで分割起動）
- 前回の選択内容を記憶

## ビルド
Android Studio (Ladybug 以降) で `SplitLauncher` フォルダを開き、Gradle 同期後に実行してください。
minSdk 26 (Android 8.0) / targetSdk 35。
※ gradle-wrapper.jar は含めていません。Android Studio が自動で用意します（CLIの場合は `gradle wrapper` を一度実行）。

### GitHub Actions でビルド
`.github/workflows/build.yml` を同梱しています。main へ push すると自動でビルドされ、
Actions の実行結果ページ下部「Artifacts」から `SplitLauncher-debug`（APK入りzip）をダウンロードできます。
Actions タブの「Build APK」→「Run workflow」で手動実行も可能です。

## 分割比率について（重要）
Android には、他のアプリを分割表示する際の比率を指定する公開 API がありません。そのため:

1. **分割画面モード**では、アプリ起動後にユーザー補助サービス「分割ランチャー 比率調整」が画面中央のディバイダーを指定位置までドラッグします。
   - 設定 → ユーザー補助 → 分割ランチャー 比率調整 を ON にしてください。
   - Android 13 以降でAPKを直接インストールした場合、「制限付き設定」によりONにできないことがあります。
     その場合は 設定 → アプリ → 分割ランチャー → 右上メニュー →「制限付き設定を許可」を実行してから再度ONにしてください。
   - 多くの端末ではディバイダーが 1:2 / 1:1 / 2:1 などの位置にスナップするため、指定値に最も近い位置になります。
   - サービスが無効の場合は 1:1 で起動します。
2. **フリーフォームモード**では比率どおりのサイズで開きます。タブレット/デスクトップモード対応端末、
   または 開発者向けオプション「フリーフォームウィンドウを有効にする」をONにして再起動した端末で使えます。

## 注意点
- 縦画面ではシステムの分割が上下になるため、「左」＝上、「右」＝下 として扱います。
- 端末（メーカー独自UI）によっては左右が逆になることがあります。その場合は「左右を入れ替え」を使ってください。
- 分割表示に対応していないアプリ（resizeableActivity=false）は分割画面に入れない場合があります。
- 起動タイミング（2つ目の起動までの待ち時間、ディバイダー操作の待ち時間）は
  `LaunchPairActivity` の `SECOND_LAUNCH_DELAY_MS` / `DIVIDER_DRAG_DELAY_MS` で調整できます。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `MainActivity.kt` | 設定画面（アプリ選択・比率・モード・ショートカット作成） |
| `LaunchPairActivity.kt` | 2つのアプリを並べて起動する透明な中継Activity |
| `DividerAccessibilityService.kt` | ディバイダーをドラッグして比率を調整 |
| `AppInfo.kt` | 起動可能アプリ一覧の取得 |
| `AppSpinnerAdapter.kt` | アイコン付きプルダウン |
| `Prefs.kt` | 選択内容の保存 |
